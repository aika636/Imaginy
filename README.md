**Русский** · [English](README.en.md)

**Расширение-надстройка** для [SillyTavern](https://github.com/SillyTavern/SillyTavern): работает
поверх популярных расширений генерации картинок прямо в сообщениях (SLAY Images и его форки) и
добавляет им то, чего в них нет — возможность **переписать промпт уже сгенерированной картинки и
перегенерировать её по-новому** в один клик, не открывая редактор сообщения и не правя JSON руками.

Не понравилась поза, свет, фон? Нажимаете карандаш рядом с картинкой, меняете текст — и получаете
новую версию.

## Коротко

- ✏️ **Карандаш рядом с картинкой** — открывает окно с промптом, стилем и соотношением сторон.
- 🔁 **«Сохранить и перегенерировать»** — новая картинка по новому тексту, без ручного перезапуска.
- 🧩 **Четыре расширения-хоста** — SLAY Images и три его форка распознаются автоматически.
- 💾 **Правка живёт в чате** — промпт записывается во все места хранения сообщения и переживает
  перезагрузку.
- 🎨 **Стиль запоминается** между картинками и чатами.
- 🔒 **Ни одного сетевого запроса** от самого Imaginy.

## Что нужно для работы

Imaginy — надстройка, сам он картинки не генерирует. Нужно, чтобы уже было установлено одно из
расширений генерации изображений в сообщениях:

| Расширение | Перегенерация одной картинки из Imaginy |
|---|---|
| [SLAY Images](https://github.com/wewwaistyping/SLAYimages) | да (кроме упавших генераций и видео) |
| [delidgi/sillyimages](https://github.com/delidgi/sillyimages) | да, включая упавшие генерации |
| [aceeenvw/notsosillynotsoimages](https://github.com/aceeenvw/notsosillynotsoimages) | да (кроме упавших генераций) |
| [0xl0cal/sillyimages](https://github.com/0xl0cal/sillyimages) | только если в сообщении одна картинка |

Правка и сохранение промпта работают со всеми четырьмя. Различается только то, может ли Imaginy сам
нажать кнопку перегенерации; если не может — он честно скажет об этом, а не сделает вид, что сработало.

Достаточно одного такого расширения — держать два одновременно не стоит, они конфликтуют между собой.

## Установка

### Способ 1 — прямо из SillyTavern (проще всего)

1. Откройте панель **Extensions** (иконка с кубиками) → **Install extension**.
2. Вставьте ссылку на этот репозиторий:

   ```
   https://github.com/aika636/Imaginy
   ```

3. Нажмите **Install** и перезагрузите вкладку.

### Способ 2 — вручную

1. Скачайте репозиторий (кнопка **Code → Download ZIP** или `git clone`).
2. Положите папку с именем `Imaginy` в каталог расширений SillyTavern:

   ```
   <SillyTavern>/data/default-user/extensions/Imaginy
   ```

   На старых сборках SillyTavern путь другой:
   `<SillyTavern>/public/scripts/extensions/third-party/Imaginy`

3. Перезагрузите вкладку SillyTavern (Ctrl+F5).

Настройки появятся в панели **Extensions** → блок **Imaginy**. Там же видно, какое расширение
генерации Imaginy распознал как активное.

## Как пользоваться

1. Наведитесь на сгенерированную картинку в чате — рядом с кнопками самого расширения появится
   **карандаш**.
2. Клик по карандашу открывает окно редактора: **промпт**, **стиль** и **соотношение сторон**.
3. Дальше два варианта:
   - **Сохранить** — новый промпт запоминается в сообщении, картинка остаётся прежней;
   - **Сохранить и перегенерировать** — сразу запускается генерация новой картинки по новому тексту
     (Ctrl+Enter делает то же самое).

Полезные мелочи:

- последний введённый **стиль запоминается** и подставляется в следующее окно редактора — рядом
  есть кнопка «Забыть»;
- если стиль или соотношение сторон жёстко заданы в настройках самого расширения-хоста, они
  перекрывают значения отдельной картинки — Imaginy предупредит об этом прямо в окне редактора;
- есть кнопка копирования промпта;
- **Esc** закрывает окно, **Ctrl+Enter** — сохраняет и перегенерирует.

Клик по самой картинке работает как раньше — открывается просмотрщик расширения-хоста, Imaginy в это
не вмешивается.

## Настройки

| Настройка | Что делает |
|---|---|
| Включить Imaginy | Полностью выключает расширение, не удаляя его |
| Показывать кнопку-карандаш на изображениях | Скрывает карандаш, оставляя расширение активным |
| Перегенерировать после сохранения промпта | Кнопка «Сохранить» сразу запускает генерацию |
| Закреплять перегенерированные картинки | Дописывает путь к новой картинке во все места, где SillyTavern хранит текст сообщения — иначе после перезагрузки страницы она может смениться обратно на самую первую |
| Запомненный стиль | Последний использованный «Стиль». Общий для всех чатов и ботов; подставляется в редакторе, когда у картинки своего стиля нет. Сам по себе на генерацию не влияет. Кнопка «Забыть» очищает его |

## Ограничения

| Что | Почему |
|---|---|
| У **видео** промпт правится, но перегенерации нет | Кнопки перегенерации у видео нет ни у одного хоста |
| У **упавших генераций SLAY Images** промпт сохраняется, но перегенерация не запускается | Кнопка «Попробовать снова» помнит старый промпт и не перечитывает новый — вместо тихой генерации по старому тексту Imaginy отказывается |
| Две картинки в одном сообщении с полностью одинаковым промптом правятся вместе | Их невозможно отличить друг от друга |

Если сохранить правку не удалось, Imaginy **не покажет, что всё хорошо** — вместо этого появится
сообщение об ошибке.

## Приватность

Imaginy **не делает ни одного сетевого запроса**. Он только редактирует данные внутри вашего чата и
нажимает кнопку расширения-хоста; вся генерация идёт через ваши собственные настройки в этом хосте.

## Разработка

Сборки нет — это обычные ES-модули, можно править файлы прямо в каталоге расширений и делать
хардрелоад вкладки.

```bash
# проверка синтаксиса
for f in index.js src/*.js src/hosts/*.js; do node --check "$f"; done

# смоук-тесты (единственная dev-зависимость — jsdom)
npm install --no-save jsdom
node tests/hosts.test.mjs
node tests/persist.test.mjs
```

Поддержка ещё одного форка того же семейства добавляется одним файлом в `src/hosts/` — остальной код
трогать не нужно. Неизвестный форк тоже подхватится: правка промпта заработает, а кнопка
перегенерации будет искаться перебором известных вариантов.
